# 책 스캔 (book-scanner)

vFlat처럼 책을 한 장씩 넘기며 찍어 PDF로 만드는 개인용 안드로이드 앱.

## 1단계 기능
- **자동 촬영(안정 감지)**: 책장을 넘기고 손을 떼서 화면이 멈추면 찍음. 같은 쪽은 자동으로 건너뜀
- **간격 촬영**: N초마다 (같은 쪽은 건너뜀) / **수동**: 셔터·볼륨키
- **펼친 두 쪽 나누기**, 추가 회전(폰을 눕혀 내려찍을 때)
- 되돌리기, 마지막 쪽 크게 보기, 탭해서 초점, 조명
- **완료 → PDF**: 사진을 다시 압축하지 않고 넣어 용량이 작음 → 공유창에서 Drive 선택 → 업로드 후 폰에서 사진·PDF 삭제

## 설치
`main`에 push하면 Actions가 빌드 → Releases에 `book-scanner.apk`. 고정 서명키라 새 버전은 덮어 설치.

## 구글 드라이브 자동 업로드 연결 (PC에서 1번만, 5분)
1. https://script.google.com → **새 프로젝트**
2. `apps-script/Code.gs` 내용을 통째로 붙여넣기 → 맨 위 `KEY`를 나만 아는 단어로 변경 → 저장
3. 위쪽 함수 목록에서 `authorize` 선택 → **실행** → 권한 검토 → 내 계정 → (고급 → 안전하지 않음으로 이동) → 허용
4. **배포 → 새 배포 → 유형: 웹 앱** / 실행 사용자: **나** / 액세스 권한: **모든 사용자** → 배포
5. 나온 웹 앱 URL(`…/exec`)을 폰으로 보내기(카톡 나에게 등)
6. 앱 ⚙ 설정 → 웹 앱 주소, 비밀키 입력 → **연결 확인** → 저장

이후 ✔완료를 누르면 드라이브 `책스캔/책이름/` 폴더에 PDF와 글자 파일(.txt)이 자동으로 올라가고 폰 사진은 지워짐.
